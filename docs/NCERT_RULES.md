# NCERT Hindi Translation Rules

1. Do not shorten or change the scientific meaning.
2. Preserve symbols, equations, units, chemical formulae and numerical values.
3. Prefer standard NCERT Hindi terminology.
4. Keep technical English terms where Hindi terminology would reduce clarity.
5. Never translate variable names.
6. Never translate or reorder answer choices.
7. Preserve question numbering.
8. Preserve List-I/List-II structure.
9. Preserve the original spatial arrangement where detectable.
10. Large standalone equations must be exported as editable Word math objects.
